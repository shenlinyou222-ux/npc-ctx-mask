# Baroque 语料（Wikipedia）

## 这是什么

`baroque.txt` 是 Wikipedia 文章 **Baroque (video game)** 的正文快照，用于 §5.3b 的"真实语料 + 51% 遮蔽"对照实验。

- 抓取时间：2026-10-26
- 用途：把"世界观/剧情"段落标记为可见，"制作/音乐/发行/评价"段落标记为受限
- 实验脚本：`scripts/baroque_bench.py`，通过环境变量指定路径：

```bash
export BAROQUE_SRC=$PWD/data/baroque/baroque.txt
python scripts/baroque_bench.py
```
