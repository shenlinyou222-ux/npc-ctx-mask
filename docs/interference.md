# 干扰曲线：回填槽位对历史记忆的影响

## 设计

固定 4 条历史事实，槽位数从 0 增到 8，每个槽位都回填子智能体的答案。
逐题单问，历史题 4 道 / 次，槽位题 NS 道 / 次，3 次试验。

## 结果

| 槽位数 | 历史准确率 | 槽位准确率 |
|---|---|---|
| 0 | **12/12** | — |
| 1 | **12/12** | 4/8（另一次 n=8 复查） |
| 3 | **12/12** | 7/9 |
| 5 | **12/12** | 11/15 |
| 8 | **12/12** | 14/24 |

## 结论一：历史记忆零干扰

槽位从 0 加到 8，历史题始终 **12/12**。回填的槽位内容不挤占模型对先前的上下文，
两者在上下文里共存而不竞争。

这是"预留空位"这个设计的关键收益：**空位在回填前不占语义，回填后也不抢注意力。**

## 结论二：槽位检索取决于提问格式

| 提问方式 | 槽位准确率 |
|---|---|
| `Q1: … Q2: … Q3: …`（带标签，一次问全部） | **12/12**（NS=3）、**20/20**（NS=5） |
| `Question: what is the access code for X? Answer:`（单问追加） | 50–75% |

这个模型对带 Q 标签的格式明显更可靠。工程上应始终用标签格式。

## 修正记录

NS=1 首次跑出 0/3，疑似异常；n=8 复查为 **4/8**，确认是小样本噪声，不是系统性失败。
