# 多槽位：N 个子智能体各占一段，按需解除

## 验证过的形态

一次 prefill 里并排放 N 段，用掩码控制哪几段可见：

| 条件 | 命中 |
|---|---|
| 一个都不遮 | **9/9** |
| **遮住 A 和 C，只留 B** | **3/9** |
| 三个都遮 | **0/9** |

逐例（n=3，三次完全相同）：

```
spans = [(3,4), (4,6), (6,8)]     # A / B / C 的块区间
all    [True,  True,  True]
onlyB  [False, True,  False]      # 只有 B 可答
none   [False, False, False]
```

**遮住两段后，恰好只剩那一段可答**——既不是"全遮导致全错"，也不是"遮了还漏"。

## 协议

```
① 主序列预留 N 段连续位置
② 子智能体 k 在 [P_k, P_k+L) 上产出结论
③ 谁返回，就解除谁那一段的掩码
④ prefill 一句**点名**的通知：「子智能体 k 已返回，结果在第 k 段」
⑤ 主智能体回答对应的问题
```

第 ④ 步必须**点名**：只有一段时说"它回来了"就够（实测 5/20 → 20/20），有 N 段时必须说清是**哪一段**，否则主智能体不知道该看哪里。

## 已验证 / 未验证

| 项 | 状态 |
|---|---|
| 多段并存 + 分别解除可见性 | ✅ 9/9 · 3/9 · 0/9 |
| 单槽位的描述性通知 | ✅ 5/20 → 20/20 |
| **多槽位 + 按名通知**（组合） | ❌ **未测** |
| 多段 + K/V 注入（而非文本写入） | ❌ 未测，HF 实现反复失败 |

**缺的那一格**：多槽位实验里是直接提问（没有通知），单槽位实验里有通知但只有一段。两者叠加——**N 段 + "第二段已返回"这种点名通知**——还没跑过。
