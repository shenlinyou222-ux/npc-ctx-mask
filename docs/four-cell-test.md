# 四格检验：换掉被遮块的内容，输出是否改变

## 设计

同一上下文、同一位置，只改两处变量：**记录 B 的编码** 与 **遮蔽开关**。

| 格 | 记录 B | 遮蔽 | 期望 |
|---|---|---|---|
| ① | code1 | 关 | 答出 code1 |
| ② | code2 | 关 | 答出 code2，且与①不同 |
| ③ | code1 | 开 | 读不到 code1 |
| ④ | code2 | 开 | 读不到 code2，且输出与③**逐字相同** |

③④ 逐字相同 = 被遮块的 K/V 对输出没有任何影响。
①② 各自答对 = 同一位置内容确实可读，排除"两次都失败"的假象。

## 结果（n=6，脚本 scripts/four_cell.py，原始数据 esults/four_cell.json）

`
① 可见时读到 code1      6/6
② 可见时读到 code2      6/6
①≠②（内容确实有用）     6/6
③ 遮蔽后泄漏 code1      0/6
④ 遮蔽后泄漏 code2      0/6
③==④（换内容无影响）    5/6
`

## 唯一不一致的一格（t4）

| | 输出 |
|---|---|
| ③（B=MSK-4546，被遮） | 4820 |
| ④（B=MSK-1544，被遮） | VIS-4820 |

两次都指向**可见记录 A 的编码**，只差一个 VIS- 前缀。也就是说：被遮块的内容没有出现在任何一次输出里，差异来自模型对可见记录的复述格式。

## 结论

**遮蔽是实质性的**：被遮块的内容换成另一串完全不同的编码后，输出不变（5/6 逐字相同，1/6 仅前缀差异）；同一位置在解除遮蔽后，两次都能正确读出各自的编码（6/6）。

这条检验与 canary（8/8 vs 0/8）、ZZZ gated（57→58）、ZZZ hidden（57→0）、Baroque（9/10=9/10，越界 5/5→0/5）互相独立，方向一致。
