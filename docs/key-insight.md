# 核心觉察：块级稀疏 + 预留空位 + 延迟解除掩码

## 一句话

> 在块级稀疏注意力下，两个共享前缀的智能体可以**把输出拼进同一条序列**：只需**提前留出空位**，后续 decode 不关注它；**等子智能体的结果到达，再解除掩码**，主智能体才重新关注那段区间和它前面那个问题。

## 拆成四个动作

```
① 预留空位      主序列在分叉点留下 [P, P+L)，占位、被遮
② 继续 decode   主智能体照常工作，看不到空位（等价于这段不存在）
③ 写入结果      子智能体在同样的绝对位置 P..P+L-1 上生成结论
④ 解除掩码      prefill 一句「它回来了」，之后的 token 才能看到这段
```

## 为什么这样成立（四条，逐条对应我们的实验）

| # | 机制要求 | 为什么满足 | 证据 |
|---|---|---|---|
| 1 | **位置必须已经确定** | 空位在分叉时就占了位置，子智能体在**相同位置**生成，因此 K 里的旋转天然正确，**不需要重旋转** | 槽位热替换 20/20 = 重 prefill 20/20，`results/` 与 `docs/reserved-slot.md` |
| 2 | **不关注 = 真的不存在** | 被遮块从 `kv_indices` 里剔除，注意力分母里没有它 | canary：被遮块 0/8，可见块 8/8；四格检验：换掉被遮块内容输出不变（5/6 逐字相同） |
| 3 | **写入后能被读到** | 解除掩码后，**之后**生成的 token 正常 attend | 延迟回答实验：先答 q2 ✔，再答 q1 ✔；不替换时 q1 答错 |
| 4 | **跨查询复用缓存** | token 序列不变，前缀缓存照常命中 | TTFT 0.98s → 0.06s（16×） |

## 最关键的那条推论：**解除掩码不追溯**

注意力是因果的：解除掩码只影响**之后**的 token。已经生成的 token 不会回头看见新内容。

这直接推出**时序约束**：

> **不能先问 q1 再等结果。** 必须先把能答的 q2 答了，等结果写入并解除掩码，再答 q1。

我们的延迟回答实验正是这个约束的正面验证：

```
q2 在空位仍被遮时回答  -> 正确（"周一下午"）
结果写入 + 解除掩码
q1 此时才答           -> 正确（KARTHA-7346）
不替换                 -> q1 答错（把实体名当编码）
```

## 与已有工作的分界

| | Star Attention | Memento | CacheBlend | **我们** |
|---|---|---|---|---|
| 块级稀疏 | ✅ 两阶段 | ✅ 遮块 | ✅ 块拼接 | ✅ |
| 谁决定可见 | 结构固定（块内局部） | 训练出的格式 | 无（全可见，重算补偿） | **业务标签** |
| 空位/延迟可见 | ❌ | ❌（memento 立刻可用） | ❌ | **✅ 预留空位 + 延迟解除** |
| 需要训练 | 否 | **是**（三阶段 SFT） | 否 | 否 |
| 跨智能体拼接 | ❌ | 单序列内 | 文本块之间 | **两个智能体的输出** |

**我们的空位是"先占位、后填内容、再开放"**——这三件事在已有工作里没有被组合过。Star Attention 的块是结构性的、生来可见；Memento 的块是"生成完立刻遮"，方向相反；CacheBlend 是"拼完再修"。

## 三个必须遵守的约束（都已实测）

1. **返回必须是自包含陈述句**——放裸答案命中 0/6，放完整句 20/20；
2. **空位长度 ≥ 返回长度**——L=22 失效、L=24 起效（对 24 token 的句子）；
3. **必须显式通知"它回来了"**——只说 `Sub-agent returned:` 时 5/20，说清"已完成/结果在上面/现在可以用"后 20/20。

## 尚未验证的一条

**多个空位并行**（3–5 个分支同时写回）没做过。单空位已验证，多空位只是同一机制的空间扩展，但槽位之间是否会互相干扰，未测。
