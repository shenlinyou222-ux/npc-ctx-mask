# 流水线：已知知识库上的标签匹配 + 重旋转

> 一句话：**知识库固定 → 按标签选出相关块 → 把选中的块重旋转成紧凑坐标 → 正常 decode**。
> 选中的块从原位置（可能跨几十万 token）搬到 `0..W-1`，模型看到的永远是一个短而密集的上下文。

本文件是把散落在 `scripts/` 里的东西串起来的入口。

---

## 一、五个步骤

```
① 建池      对知识库做一次 prefill，保存每层的「未旋转 K」和 V
② 标签匹配  确定性地按标签选出本次需要的块（不用向量检索）
③ 重旋转    K 按紧凑坐标重新旋转（fp32），V 原样
④ 组缓存    拼成 0..W-1 的缓存，问题接在 W
⑤ decode    正常生成；后续多轮直接追加，不再重排
```

### 为什么 K 要存成「未旋转」

RoPE 在存进缓存时就把位置写死了。要搬动一个块，只能「反旋转 + 重旋转」。
存未旋转的 K，重定位就只是一次逐元素乘，**O(W·d)，不用重算**。

### 为什么必须 fp32 旋转

| 旋转精度 | 平移 1000 后的注意力分数误差 |
|---|---|
| fp32 | **9.4e-04** ✔ |
| bf16 | 绝对差 1.34，**相对差 32%** ✘ |

K 可以存 bf16，但**旋转时必须升 fp32 再降回**。

## 三、实测（Qwen3-1.7B bf16，单卡 8 GB）

### 自检

| 项 | 结果 |
|---|---|
| 重旋转 vs HF 原生 | 误差 **0.000e+00** |
| 提取 + 重紧凑 vs 直接前向 | `max|Δlogits|` = **0.125**（bf16 噪声级） |
| decode 位置接续 | 两条路径最终位置都是 65 ✔ |

### 查找类（问某一块里的编码）

| 臂 | 命中 | 每次请求 |
|---|---|---|
| full（全部可见） | 12/12 | 0.400 s |
| **池里取 S0+目标块** | **12/12** | 0.073–0.12 s |
| 故意取错块 | 1/12 | 0.073 s |

### 推理类（比较两块，必须同时看到）

| 臂 | 命中 |
|---|---|
| full（468 token，含填充） | 14/20 |
| fresh（只 prefill 两块） | 20/20 |
| **池里取两块 + 重紧凑** | **18/20** |
| only_A / only_B（捷径检测） | 10/20 / 10/20 |

### 多轮会话（873 token → 紧凑前缀 45–48 token，压缩 ~19×）

| 指标 | 全上下文 | 紧凑 |
|---|---|---|
| 第 1 轮（比较） | 4/10 | 4/10 |
| 第 2 轮（计数） | 8/10 | 9/10 |

第 2 轮是普通追加，**没有任何位置处理**。

## 四、必须注意的坑

### 1. 题目不能有捷径

判"是否 A 比 B 多"这种 yes/no 题，只看一块也能靠偏置蒙对。
**凡是"需要多块"的题目，必须加 `only_A` / `only_B` 对照臂**，否则测不出真效应。

### 2. 系统提示要一起选

从池里只取目标块、漏掉 S0，会掉到 6/12——问题格式指令在 S0 里。

### 3. 同进程连跑多个 trial 会崩

反复大块分配后驱动进入坏状态（`CUDA driver error: device not ready`），
重启 WSL 也无效。**改成每个 trial 独立进程即可**（`run_session.sh` 就是这么做的）。

### 4. 物理缓存长度必须等于紧凑长度

满足时 HF 自动续位，decode 不需要任何位置处理；
带洞的物理缓存就必须显式传 `position_ids`，而那条路在 HF 里是坏的（实测 0/5）。

## 六、与已有工作的关系

| 工作 | 关系 |
|---|---|
| **InferScale**（2607.27090） | 同样的 chunked RoPE 与"存未旋转 K"，但用于**离线事实注入**；我们用在同一段长上下文的事后选择 |
| **RoPERelay**（2610.21126） | 同样做紧凑坐标重排，用于稀疏 KV 驱逐；我们用于池化选择 |
| **Kamera**（2606.23581） | 报告跨块条件化丢失；我们的 18/20 vs 20/20 是同一现象 |
| **Leyline**（2606.01065） | 策略驱动的区间编辑原语 |
| **CacheBlend**（2405.16444） | 非前缀块复用必须重算 ~15%；我们不重算，只重旋转 |

**本目录的定位**：把上面几篇的机制组合成一条可跑通的流水线，并给出 HF 上的端到端数据。
