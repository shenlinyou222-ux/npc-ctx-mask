# 长上下文：历史与槽位随长度的变化

## 曲线（槽位固定 3 个并回填）

| 历史条数 | 上下文 token | 历史准确率 | 槽位准确率 |
|---|---|---|---|
| 4 | 192 | 8/8 | 6/6 |
| 16 | 372 | 12/12 | 5/6 |
| 32 | 616 | 10/12 | 4/6 |
| 64 | 1110 | 9/12 | 1/6 |
| 128 | 2110 | 9/12 | 3/6 |
| 256 | 4195 | 8/12 | 2/6 |

## 关键对照：同样长度但不放槽位

| 历史条数 | 无槽位 | 有槽位（回填） |
|---|---|---|
| 64（≈1.0K tok） | **11/12** | 9/12 |
| 128（≈2.0K tok） | **11/12** | 9/12 |
| 256（≈4.1K tok） | **10/12** | 8/12 |

## 结论分两段

**短上下文（≤ 616 token）：零干扰。** 槽位 0→8 个，历史始终 12/12（见 `docs/interference.md`）。

**长上下文（≥ 1K token）：轻微干扰，但幅度小。** 同样长度下，有槽位比无槽位少 1–2 道题
（92% → 75%，83% → 67%）。

## 必须声明的限制

每个格子只有 **n=2 次试验、12 道题**。1–2 道题的差距**在噪声范围内**，方向一致但幅度不可靠。
要下"长上下文有干扰"的结论，至少需要 n=8 以上。

## 槽位检索随长度退化更明显

| 长度 | 槽位准确率 |
|---|---|
| 192–616 tok | 67–100% |
| 1.1K–4.2K tok | 17–50% |

这条退化比历史更陡，且与 RULER 类报告的"有效上下文远小于声称窗口"一致。
