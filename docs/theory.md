# 理论定位：这不是消息传递，是带权限位的共享地址空间

> 核实程度：`正文` = 读过摘要/原文；`引用` = 经典文献，本轮未核对原文。
> arXiv 检索接口当时限流，只核对了能打开的页面。

## 一、三种多智能体通信范式的对照

| | 消息传递（Actor 模型） | 黑板（Blackboard） | **我们** |
|---|---|---|---|
| 状态在哪 | 各 agent 私有 | 共享结构 | **共享序列 + 权限位** |
| 通信动作 | 拷贝消息 | 读写黑板 | **在同一地址写 K/V** |
| 代价 | 每跳重 prefill | 取决于实现 | **0（位置已预留）** |
| 可见性 | 无（收到就能看） | 全局 | **逐段可控** |
| 控制方式 | 显式寻址 | 机会式 | **谁返回就解除谁** |

**一句话**：现有 agent 框架是消息传递（Hewitt 的 actor 模型，`引用`），我们是**共享地址空间 + 分页保护**。

## 二、最贴切的理论前身：元组空间（Linda）

Gelernter 1985 提出的 **generative communication**（`引用`）：agent 不直接对话，而是把元组 `out()` 进共享空间，别的 agent 用 `in(模板)` 取。关键性质是**空间与时间解耦**——写者和读者不必同时在场。

我们的机制几乎逐条对应：

| Linda | 我们 |
|---|---|
| `out(tuple)` | 子智能体写 K/V 到槽位 |
| `in(template)` | 主智能体按可见性读 |
| 空间解耦 | 槽位位置固定，写者不必在主序列里 |
| 时间解耦 | 主智能体可以先答别的，等返回再解除 |

**唯一但关键的差别**：Linda 的匹配是**内容匹配**（模板对元组），我们的匹配是**权限匹配**（谁能读这一段）。后者是 Linda 没有的维度，也是我们的贡献所在。

## 三、第二个对应：分布式共享内存与缓存一致性

DSM 的核心问题是**一致性**：多个处理器怎么看到同一个内存的一致视图（Li & Hudak 1989，`引用`）。经典解法是失效/有效（invalidate/validate）协议。

我们的"解除掩码"就是一次 **invalidate → validate** 转换：

```
预留空位   -> 该页存在但不可读（invalid）
子智能体写 -> 该页内容就位（仍是 invalid）
解除掩码   -> validate，之后的读能命中
```

**但我们比 DSM 简单得多**，因为我们的槽位是 **单写者（singly-owned）**：每个槽位只有一个子智能体写，不存在写-写冲突，不需要一致性协议，只需要可见性位。这是一个可以写进论文的简化论证。

## 四、与"学习式通信"的关系

TarMAC（arXiv 1810.11187，ICML 2019，`正文`）让 agent 学两件事：**发给谁**（targeting）和**发什么**（message），全部由下游奖励学出来，没有通信监督。

我们的对应物：

| TarMAC | 我们 |
|---|---|
| 学"发给谁" | **不需要**：槽位位置就是地址 |
| 学"发什么" | 子智能体正常生成，不训练 |
| 连续向量消息 | **K/V 块**（天然连续、高维） |
| 需要训练 | **不需要** |

所以我们的定位可以说：**把"学出来的定向通信"变成"结构化的定向通信"，代价是表达能力受限于预训练模型的 K/V，收益是零训练。**

> 这一点需要谨慎：我们没有做过与 TarMAC 的对照实验，不能说"更好"，只能说"不需要训练"。

## 五、信息论视角：共享前缀就是边信息

设主智能体的共享前缀为 $S$，子智能体看过 $C_k$，要回答的问题是 $Q_k$。返回消息 $M_k$ 真正需要承载的是

$$I(\text{answer}_k ; C_k \mid S, Q_k)$$

也就是**在共享上下文之外**的那部分信息。共享越多，这个条件互信息越小，消息可以越短。

这给出一条**可测预测**：

> 共享前缀越长，返回消息所需的 token 数越少；极端情况下返回一个 token 就够。

我们没有测过这条，但它可以从现有数据间接支持：子智能体返回的"自包含句子"（20/20）比"裸答案"（0/6）效果好，说明返回消息里包含了**超出条件互信息**的冗余——那部分是帮助模型定位的，不是信息本身。

## 六、可检验的推论（尚未做）

| 推论 | 设计 |
|---|---|
| 共享前缀 ↑ → 返回消息可 ↓ | 固定任务，扫前缀长度与返回长度 |
| N 的上界 = 模型工作记忆 | 我们测到 N≤3 成立、N≥4 失效（Qwen3-4B），换更大模型应上移 |
| 权限匹配 vs 内容匹配 | 同样内容，只改可见性，输出应只随可见性变（已由四格检验支持） |

## 七、N 的扩展实测（本节数据来自本轮实验）

| N | 逐段单独放回 | 跨段泄漏 | 全遮对照 |
|---|---|---|---|
| 3 | **9/9**（明细 [1,1,1]） | 0 | 3/3 |
| 4 | **3/12**（明细 [1,0,0,0]） | 0 | 3/3 |
| 5 | **3/15**（明细 [1,0,0,0,0]） | 0 | 3/3 |

**断点在 N=3 与 N=4 之间**：N≥4 时模型只回答 Q1，无论通知点名哪一题。

注意：泄漏始终为 0，全遮对照始终正确。**失效的是"按通知选问题"，不是"掩码"**——这两件事必须分开说。
