# Reserved slot + hot swap: the coordinator waits for a sub-agent

## The shape being tested

```
主序列:  S            [槽位 P..P+L-1]   q   "Coordinator: 我不知道，等子智能体"  <WAIT>
                        ↑ 主智能体 decode 期间这块不可见（块掩码）

子智能体: S (共享前缀) + 自己的任务  -> 产出总结，正好落在 P..P+L-1

返回:    把总结的 K/V 写进主 cache 的 P..P+L-1，解除掩码
        再 prefill 一句「子智能体已完成并返回了结果，现在可以用它回答」
主智能体: 回答
```

关键点：**槽位位置在分叉时就已知**，所以不需要动态分配位置，只需要子智能体“从 P 开始写”。

## 结果（Qwen3-1.7B，随机编码，n=20/臂）

| 臂 | 含义 | 命中 |
|---|---|---|
| `reprefill` | 同样的内容全量重跑（上限参照） | **20/20** |
| `wait_swap` | **热替换** | **20/20** |
| `wait_full` | 总结一开始就在槽位 | 20/20 |
| `wait_noswap` | 从不替换（下限参照） | **0/20** |

**热替换与全量重跑完全等价**，而不替换则完全答不出（它只能从共享记录里抓另一个实体的码）。

早期版本（简单任务、无等待语义）：`full` / `hotswap` / `hotswap_noplan` 在思考长度 8/16/32 下各 **20/20**，`empty` **0/20**。

## 四个把实验做错的坑（按发现顺序）

| # | 错误 | 现象 | 修法 |
|---|---|---|---|
| 1 | **原地改写 cache** | 替换后完全无效，与不替换一致 | HF 的 `DynamicCache` 必须**重建**：clone → 改切片 → `update()` |
| 2 | **总结在零上下文下生成** | 替换后仍答错 | 子智能体必须**带共享前缀 S** 产出总结（位置 0..P-1 是 S，总结在 P..P+L-1），否则表示太弱 |
| 3 | **返回提示只有一句 "Sub-agent returned:"** | swap 5/20，连 full 也只有 15/20 | 改成完整描述，见下 |
| 4 | **截断陈旧尾巴 + 重 prefill** | 0/20 | cache 截断后位置记账出错；而且**不必要**——见结论 |

## 第 3 条是决定性的

同一批样本、同一个 swap 实现，只改“返回后 prefill 的那句话”：

| 返回提示 | swap | full |
|---|---|---|
| `\nSub-agent returned: ` | 5/20 | 15/20 |
| `[System note] The sub-agent has finished its work and returned the result shown above. You may now use that result to answer the question.` | **20/20** | **20/20** |

也就是说：**光把内容写进 cache 不够，必须显式告诉模型“事件发生了”**。而且这句话必须说清三件事：

1. 子智能体**完成了**；
2. 结果**就在上面**；
3. 现在**可以用它回答**。

## 结论

1. **机制成立**：预留槽位 + 热替换 = 全量重 prefill（20/20 = 20/20），而不替换是 0/20。
2. **不必要截断历史**：陈旧的 `<WAIT>` 尾巴在有了正确描述后不再是障碍（20/20），所以不需要 cache 回滚。
3. **描述是协议的一部分**：bare marker 会让命中率掉到 1/4，而且连“内容本来就在”的上限臂也掉——说明这是**提示质量**问题，不只是 cache 问题。

## 仍然缺的

1. **引擎要支持“从位置 P 开始写”**：现在只能在 HF 里手动给 `position_ids`；vLLM 不暴露。
2. **块粒度**：槽位必须是 16 token 的整数倍（FlexAttention），总结短了要补齐。
3. **多分支**：只测了单槽位单分支。
4. **块掩码未参与**：实验里槽位放的是可见占位符（`.`），没有真正用 deny-list 遮住；接入掩码后需要确认“不可见”不会额外影响主智能体的思考质量。
5. **一个模型、一种任务**：Qwen3-1.7B，单跳查表。

## 复现

```bash
python scripts/slot_batch.py 20 8    # 简单任务，思考长度 8
python scripts/slot_wait.py 20       # 等待-返回流程，四臂对照
```
